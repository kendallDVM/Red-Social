SOCIAL UNA - Red Social Estudiantil
Proyecto Final de Estructuras de Datos - Kendall, Greivin y Mariano

REQUISITO
  Java 17 o superior. Para verificarlo, en una terminal: java -version

COMO ABRIR LA APLICACION
  Opcion 1: doble clic en run.bat
  Opcion 2: en una terminal, dentro de esta carpeta: java -jar SocialUNA.jar
  Opcion 3: doble clic en SocialUNA.jar (solo funciona si Windows abre los .jar con Java 17 o superior)

  Importante: SocialUNA.jar debe estar junto a la carpeta data\, donde se guardan
  y leen los datos (usuarios.json, amistades.json y publicaciones.json).
